Android setup

Install in
three steps.

The APK is free to download directly from GitHub. No Play Store account is required.

01

Download the APK

Tap Get Android APK above and choose the file ending in .apk.

02

Allow this source

If Android asks, enable Allow from this source for your browser or file manager, then return and install.

03

Enable music access

Open the app, choose Enable Spotify access, allow notification access, and return to the app.

TIP

Android Auto

Connect your phone, open the media-source picker, and select NowPlaying Visuals. Driving mode shows safe media controls, not the full visualizer.

What it does

Less player.
More presence.

It reads the music already playing and turns it into a focused visual layer you can make your own.

01

Lyrics that follow

Time-synced lyrics update with the current track and recover when Spotify reconnects.

02

Color from the music

Album art shapes the atmosphere, or use your own theme with precise HSL sliders.

03

A canvas you control

Drag, resize, and save layouts for lyrics, cover art, title, status, clock, and more.

04

Light on the desktop

A native Rust backend keeps media updates responsive without becoming another heavy player.
