# Contributing

Fork the project, create a branch, and submit a pull request. By opening a pull request, you confirm that the work is yours to contribute and agree that no contribution is accepted until you have signed a separate contributor license agreement or copyright assignment accepted by Gabe Winstead.

Install dependencies with `npm install` and run `npm run tauri dev` to test locally. Run `npm run build` for the frontend and `npm run tauri build` before submitting Windows packaging changes.

Contributors are credited for the specific work they author, but do not receive ownership of the project. Do not redistribute, sell, sublicense, or use the project commercially. Do not remove required attribution or license notices.
